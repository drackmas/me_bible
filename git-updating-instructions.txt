ok so say we make more code changes like we normally do. how do I do updates for git? Assume I'm a newbie which I am. The main thing I know is I probably do git add .  first?

Here’s a simple, beginner-friendly workflow you can follow every time you make changes.Normal update process (do this every time)bash

# 1. See what files you changed
git status

# 2. Add all the changed files
git add .

# 3. Save the changes with a message
git commit -m "Describe what you changed"

# 4. Upload to GitHub
git push origin main

ExampleLet’s say you fixed the tag matching and updated a few files:bash

git status
# (shows the files you changed)

git add .

git commit -m "Fix tag matching to be case-sensitive and whole-word"

git push origin main
